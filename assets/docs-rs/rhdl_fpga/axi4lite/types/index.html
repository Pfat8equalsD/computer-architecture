The AXI bus types

This module includes basic types and type definitions required by the AXI specification. Although there are clearly more ergonomic ways to represent these values in rhdl (the ResponseKind, for example, could easily be an enum), we use basic raw types here since we need to export these signals to other cores that are likely not implemented in rhdl.
